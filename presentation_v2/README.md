## Contents

PPT共15页，前13页按15分钟安排，第14页参考文献，第15页致谢。
逐页讲稿约3300汉字，含计时、切页提示、9项备用问答及引文核对清单；同一讲稿已写入PPT备注。

按主文献三部分组织：

1. 李宏龄与票号文书：两部书的区别，以及班期、用人方面的经营实例。
2. 票号成败与银行改制：经营危机、各埠来信中的银行优势、联合办行方案、梁启超的比较及二元对立争论。
3. 有限责任与公司制度：风险分担、三个投资者行为机制、逆向选择和框架效应、政府介入的理由，以及票号治理与公司制度环境。

古文采用短句节录，并配解释和印刷页码。引文均转引何平文章；莫斯等其他原书未另行核阅。
主文献：何平《李宏龄的票号成败论与近代中国公司制度的缺失》，《中国钱币》2022年第6期，第39—49页。

文件名为英文，正文为中文。初版保留在仓库的 presentation 文件夹。
