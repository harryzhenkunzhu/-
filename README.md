# Li Hongling Presentation

货币思想史课堂展示：《李宏龄的票号成败论与近代中国公司制度的缺失》。

PPT含13页正文、2页附录。逐页讲稿按14分40秒安排，附计时、切页提示和备用问答。
主文献为何平《中国钱币》2022年第6期文章；与《别无他法》第3章的理论联系控制在一页。
