# 概率论与数理统计第1—3章复习课

## 文件

- `概率统计1-3章复习课.pdf`：教师授课版，59页，包含55页正文与4页选讲附录；每章2题，共6题，附7页详细答案。
- `概率统计1-3章复习课-学生版.pdf`：52页，隐藏上述章后练习的答案页，保留讲授中的例题。
- `probability_review.tex`：完整、可编辑的Beamer源码。图示均为TikZ矢量图，无外部图片依赖。

## 编译

推荐使用Overleaf，编译器选 **XeLaTeX**，主文件设为 `probability_review.tex`。

本地使用带中文支持的TeX Live或MiKTeX，需有 `beamer`、`xeCJK`、`amsmath`、`mathtools`、`booktabs`、`tikz`、`appendixnumberbeamer` 等常见宏包。运行两次：

```sh
xelatex probability_review.tex
xelatex probability_review.tex
```

字体依次自动选择Noto Sans CJK SC、微软雅黑、Fandol黑体。拉丁文字使用Latin Modern。一般不需要改字体设置。

源码开头有 `\def\StudentVersion{1}` 开关：取消该行注释，重新编译两次即可生成隐藏章后答案的学生版；重新注释后编译即可恢复教师版。答案由 `answerframe` 环境统一控制。

源文件内附有少量不显示在投影中的 `\note{...}` 教学提示。

## 整理时的统一与校正

- 已读取压缩版笔记，共22页；按前三章组织，第22页进入第四章的数学期望内容不纳入本课。
- 笔记的指数分布使用尺度参数 `θ`；课件统一使用率参数 `λ=1/θ`，避免与习题中的不同写法混淆。第24页明确两者对应关系。
- 笔记第4页检测例题重新计算为约4.72%。课件区分灵敏度、特异度与阳性后的患病概率。
- 独立正态变量相加的结论明确补上独立前提；区分边缘正态与联合二维正态。
- 第二章练习2沿用原题查表精度：`z≈1.55`、`p≈0.0606`，结果约0.2296；若不做中间查表舍入，数值约0.22916，差别来自舍入。
- 连续分布函数不一定严格递增；概率积分变换不沿用“连续就一定有普通反函数”的论证。
- 乘积与商的密度公式按统一变量重写，保留雅可比因子的绝对值。
- 所有选用练习均重新核算。教师版和学生版均使用XeLaTeX编译并检查排版。
